# 01 · 製品仕様

## 1. プロダクト定義

**WAKARU** は、手元の資料（PDF・スライド・画像・音声・動画・表計算・テキスト・コード・Webリンク）を取り込み、
**「読んでいるページをその場で解説する」** ことと **「資料全体を根拠に対話・制作する」** ことを両立させる、ローカルファーストのデスクトップAIノートブック。

接続先AIは **OpenAI API互換または Anthropic API互換のエンドポイント**。クラウドAPI／LM Studio／Ollama 等を共通の内部メッセージ形式で扱う。
文字起こしは **whisper.cpp** をローカル実行する。

### 一行での価値

> 難解な資料を、いま見ているそのページのまま、わかるようにする。

### ターゲットユーザー

- 論文・技術資料・講義スライドを読む学生／研究者／エンジニア
- 会議録画・講演音声を資料化したい人
- クラウドに資料を上げたくない（ローカルLLMを使いたい）人

## 2. スコープ

### v1.0 に入るもの（In Scope）

- プロジェクト管理（作成・アーカイブ・削除・エクスポート・インポート）
- ソース取り込みと解析（[`04_取り込みパイプライン.md`](04_取り込みパイプライン.md) の全形式）
- Viewer（ファイルツリー + マルチタブプレビュー、編集不可）
- Live Illustrator（ページ単位の逐次解説 + 継続する対話 + プロジェクト全体RAG）
- Studio（RAGチャット、MCP、サンドボックス内でのコマンド実行とファイル生成）
- File Modifier（画像→PDF、テキスト→整理MD/TXT）
- 全文横断検索
- 設定（AI・言語・テーマ・モノトーン・表示サイズ・プロジェクト管理）

### v1.0 に入れないもの（Out of Scope、明示的に）

- ソースファイルの**編集**（プレビューのみ。草案の明記に従う）
- クラウド同期・アカウント・課金
- 複数人での共同編集
- モバイル／Web版
- 画像生成
- OCR以外の手書き認識、数式のLaTeX完全復元（best-effortに留める）

## 3. 機能要件（FR）

IDは実装・テストから参照する。

### FR-P: プロジェクト

| ID | 要件 |
|---|---|
| FR-P1 | ホームからプロジェクトを新規作成できる（名前必須、説明は任意）。 |
| FR-P2 | プロジェクトは1つのフォルダとして自己完結する（[`03_データモデル.md`](03_データモデル.md) §2）。 |
| FR-P3 | プロジェクト内設定からプロジェクトをZIPでエクスポートできる。ZIPは `schemaVersion` を持つ。 |
| FR-P4 | 設定画面またはホームからZIPをインポートできる（OSのファイル選択ダイアログを使用）。 |
| FR-P5 | プロジェクトをアーカイブできる（一覧から隠れるがデータは残る）。復元できる。 |
| FR-P6 | プロジェクトを削除できる。削除は**プロジェクト名の再入力による確認**を要求する。 |
| FR-P7 | プロジェクト一覧はチェックボックス付きリストで、複数選択して一括エクスポート／アーカイブ／削除ができる。 |

### FR-S: ソース

| ID | 要件 |
|---|---|
| FR-S1 | ドラッグ&ドロップ、ファイル選択ダイアログ、フォルダ一括、URL入力の4経路で追加できる。 |
| FR-S2 | 追加時に原本を `sources/` にコピーし、SHA-256で重複を検出して警告する。 |
| FR-S3 | 解析はバックグラウンドジョブで行い、進捗（`queued / analyzing / ready / failed`）をUIに表示する。 |
| FR-S4 | 解析失敗時はエラー理由を保持し、単体で再実行できる。 |
| FR-S5 | 解析結果（AIが読める形）を `derived/` に保存する。原本は不変（I-3）。 |
| FR-S6 | ソースを削除すると、原本・派生物・チャンク・埋め込みが全て消える。 |
| FR-S7 | 対応形式：PDF, PPTX, DOCX, 画像(png/jpg/webp/gif/bmp/tiff/heic), 音声(mp3/wav/m4a/flac/ogg/aac), 動画(mp4/mov/mkv/webm), 表計算(xlsx/xls/csv/tsv), md, txt, JSON, JSONL, コードファイル, Webリンク。 |

### FR-V: Viewer（資料を見るタブ）

| ID | 要件 |
|---|---|
| FR-V1 | Viewer は独自のタブ群を持つ。最左は「ソース一覧タブ」（ホームアイコン）で**閉じられない**。 |
| FR-V2 | ソース一覧タブは File explorer 風のツリー／リスト表示。ソート・フィルタ・検索ができる。 |
| FR-V3 | ファイルを開くと**ホームタブの右側**にタブが追加される（草案の「左側」は誤記、C-4）。 |
| FR-V4 | プレビューは**閲覧専用**。編集UIを出さない。 |
| FR-V5 | Live Illustrator がオンのとき、右端からドロワーを引き出せる。オフのときはハンドルも出さない。 |
| FR-V6 | タブは並べ替え・ピン留めができ、プロジェクトを閉じても復元される。 |
| FR-V7 | 対応プレビュー：PDF/スライド（ページ送り）、画像（ズーム/パン）、音声・動画（波形/シークとトランスクリプト同期）、表計算（グリッド）、テキスト/MD/コード（シンタックスハイライト付き読み取り専用）、Webリンク（保存されたリーダービュー）。 |

### FR-L: Live Illustrator

| ID | 要件 |
|---|---|
| FR-L1 | アプリ設定でグローバルにオン/オフできる。プロジェクト単位でも上書きできる。 |
| FR-L2 | 閲覧中のページ／スライド／時刻区間／シートが変わると、その単位の解説を自動生成する。 |
| FR-L3 | 解説は**平易な文章に噛み砕いたもの**（草案：「わかりやすく理解しやすい形に文章にしてくれる」）。詳細度を3段階（かんたん／標準／くわしい）から選べる。 |
| FR-L4 | 解説からそのまま質問できる。**質問と回答は永続化され、次回同じページを開いたとき続きから質問できる**（草案の明示要件）。 |
| FR-L5 | Live Illustrator のチャットは、そのページだけでなく**プロジェクト全体をRAGとして参照できる**（草案の明示要件）。参照範囲は「このページのみ／このソース／プロジェクト全体」から選択、既定は「このソース」。 |
| FR-L6 | 現在開いている Live Illustrator のスレッドを **Studio タブへインポートできる**（草案の明示要件）。 |
| FR-L7 | 生成済み解説はキャッシュされ、同一条件（ソース×ロケータ×モデル×言語×詳細度）では再生成しない。手動で再生成できる。 |
| FR-L8 | 生成中はストリーミング表示し、ページを離れたら中断する。 |

### FR-T: Studio

| ID | 要件 |
|---|---|
| FR-T1 | Studio は上部に独自のタブ群を持ち、**自由に追加できる**。 |
| FR-T2 | 各タブは独立したスレッド。タブ名は自動命名＋手動リネーム可。 |
| FR-T3 | ソースをRAGとして普通にチャットできる。 |
| FR-T4 | **他のStudioタブの内容、および Live Illustrator タブの内容を必要に応じて参照できる**（草案の明示要件）。参照は明示的な指定（`@タブ名`）と、モデルが呼べるツール（`read_tab`）の両方で可能。 |
| FR-T5 | 接続したMCPサーバのツールを呼び出せる。ツール実行は既定で都度承認。 |
| FR-T6 | プロジェクト専用ワークスペース内でコマンドを実行し、ファイルを作成できる。**サンドボックス外に出られない**（I-7）。 |
| FR-T7 | 生成したファイルは (a) ソースに追加、(b) ダウンロードフォルダにコピー、のいずれもできる。 |
| FR-T8 | 回答には引用が付き、クリックでViewerの該当ページを開く。 |

### FR-F: File Modifier

| ID | 要件 |
|---|---|
| FR-F1 | 左サイドバーの上から2番目に常駐する（プロジェクトに属さない）。 |
| FR-F2 | **画像→PDF**：複数画像を並べ替え、ページサイズ・向き・余白を指定してPDF化。出力フォルダを選んで出力。 |
| FR-F3 | **テキスト→MD/TXT**：貼り付けたテキストを、AIで整理したMarkdown、またはそのままのTXTとして保存。出力フォルダを選んで保存。 |
| FR-F4 | MD整理は専用システムプロンプトを用い、**正確に、要点を落とさず**整形する（草案の明示要件）。整形前後を並べて差分確認できる。 |
| FR-F5 | 出力前に必ずプレビューを見せる。上書きになる場合は確認する。 |

### FR-N: ナビゲーション・検索

| ID | 要件 |
|---|---|
| FR-N1 | 左サイドバーは出し入れ可能。**半透明で、開いたとき現在のページの上に覆いかぶさる**（草案の明示要件。押し出しレイアウトにしないこと）。 |
| FR-N2 | サイドバーの並びは上から：**ホーム → ファイルモディファイヤ → 各プロジェクト → 検索タブ（最下部）**。 |
| FR-N3 | 検索タブは全プロジェクト横断で、ソース名・本文・スレッド・アーティファクトを検索できる。 |
| FR-N4 | サイドバーはキーボード（`Cmd/Ctrl+B`）で開閉、`Esc` で閉じる。開いている間、背後はスクロールロック。 |

### FR-A: AI設定

| ID | 要件 |
|---|---|
| FR-A1 | OpenAI互換またはAnthropic互換のプロファイルを複数登録できる（API形式、名前、Base URL、APIキー、既定モデル）。 |
| FR-A2 | 接続テストで `/v1/models` を叩き、到達性とモデル一覧を確認できる。 |
| FR-A3 | 役割（chat / vision / embedding / organizer）ごとに使うプロファイル＋モデルを割り当てられる。 |
| FR-A4 | whisper.cpp モデル（base / small / medium / large-v2）をアプリ内でダウンロード・削除・選択できる。 |
| FR-A5 | APIキーはOSキーチェーンに保存する（I-4）。 |

### FR-C: 設定（草案「絶対入れるやつ」）

| ID | 要件 |
|---|---|
| FR-C1 | AIの設定（FR-A1〜A5） |
| FR-C2 | 言語設定：**English / 日本語 / 中文（簡体）**。UI言語とAI応答言語を別々に設定できる。 |
| FR-C3 | 表示モード：ライト／ダーク／システム追従 |
| FR-C4 | **モノトーン切替**：アプリ内のUIから開いている資料まで、**表示されているもの全てを白黒にする**（草案の明示要件） |
| FR-C5 | 表示サイズ変更：**文字とUIの両方**。80% / 90% / 100% / 110% / 125% / 150% |
| FR-C6 | チェックボックス付きリストでのプロジェクト管理：選択→ZIPダウンロード／インポート／アーカイブ／削除 |

## 4. 非機能要件（NFR）

| ID | 要件 | 検証方法 |
|---|---|---|
| NFR-1 | **起動時間** コールドスタート 3秒以内（プロジェクト0件時）、5秒以内（プロジェクト20件時） | 手動計測、CIで警告 |
| NFR-2 | **ページ切替** Viewer のページ送りは 150ms 以内に描画開始 | プロファイリング |
| NFR-3 | **Live Illustrator 初動** 解説の最初のトークンが 3秒以内に出る（キャッシュヒット時は即時） | 手動計測 |
| NFR-4 | **検索応答** 1万チャンクに対しハイブリッド検索 300ms 以内 | ベンチマーク（Phase 3のAC） |
| NFR-5 | **オフライン動作** ネット遮断時、閲覧・検索・エクスポート・File Modifier(TXT)が動く（I-2） | 手動：機内モードで通し |
| NFR-6 | **メモリ** 100ページPDF × 10ソースのプロジェクトで常駐 1.5GB 以内 | 実測 |
| NFR-7 | **バイナリサイズ** インストーラ 120MB 以内（whisperモデル・pdfium別DLを含まず） | ビルドサイズ計測 |
| NFR-8 | **アクセシビリティ** WCAG 2.1 AA。本文コントラスト 4.5:1、UI要素 3:1、フォーカスリング必須、全操作キーボード到達可能 | axe + 手動タブ移動 |
| NFR-9 | **データ耐障害性** 強制終了しても `project.db` が壊れない（WALモード＋トランザクション） | kill -9 テスト |
| NFR-10 | **プライバシー** テレメトリ・自動送信を一切実装しない。外部通信はユーザーが設定したAIエンドポイント、明示的なURL取り込み、モデルDLのみ | コードレビュー＋通信ログ |
| NFR-11 | **対応OS** macOS 12+ (arm64/x64)、Windows 10+ (x64)、Linux (x64, deb/AppImage) | 各OSでスモークテスト |

## 5. 主要ユーザーフロー

### UF-1: はじめての解説（最重要フロー）

1. ホームで「新規プロジェクト」→ 名前を入力
2. PDFをドラッグ&ドロップ → 進捗バー付きで解析
3. `ready` になったらクリック → Viewerタブが開く
4. 右端のハンドルを引く → Live Illustrator が現在ページの解説をストリーミング
5. 「この式の意味は？」と質問 → ページ画像＋抽出テキスト＋関連チャンクを根拠に回答、引用付き
6. アプリを閉じて翌日再開 → 同じページを開くと**前回の会話が残っている**

### UF-2: 講演動画を資料化

1. mp4を追加 → 音声抽出 → VAD → whisper文字起こし → セグメント化 → インデックス
2. Viewerで動画を開く → トランスクリプトが時刻同期で並ぶ
3. Studioタブで「この講演の要点を10項目のMarkdownに」→ ワークスペースに `summary.md` 生成
4. 「ソースに追加」→ 以後そのMarkdown自体もRAG対象になる

### UF-3: プロジェクトの持ち出し

1. プロジェクト内設定 → エクスポート → ZIP保存
2. 別マシンで 設定 → プロジェクト管理 → インポート → ZIP選択
3. `schemaVersion` を検査 → 必要ならマイグレーション → そのまま再開できる
