# 06 · UI仕様

> **2026-09-07 / v0.0.5 現行デザイン:** GUIは無彩色の会話型ワークスペースへ更新した。
> 白/黒の本文面、淡いサイドバー面、塗りの選択行、12px前後の丸いコントロール、中央会話カラムと
> 一体型コンポーザーを共通言語とする。画面階層と機能要件は本書のまま維持する。実装値の一次情報は
> `src/styles/tokens.css`、人間向けの現行契約はリポジトリ直下 `design.md` とする。

## 1. デザイン規律の適用範囲（先に読むこと）

草案は「Hallmarkに従い、できるだけ不要な大きすぎる余白であったりを避け、見やすさを重視する」と指定している。
一方、Hallmark（`元/hallmark/`）は**ランディングページ向け**のデザインスキルである。したがって適用範囲を明確に切る。

### 適用する（守る）

| Hallmark参照 | 適用内容 |
|---|---|
| `references/color.md` | **色はOKLCHトークンへ集約する。現行テーマではライトの白とダークの黒を基準面として許可し、面の階層は無彩色の明度差で作る。パープル→シアン系グラデは禁止。** |
| `references/typography.md` | 2+1フォント規律。見出しは常にローマン体（**斜体見出し禁止**）。 |
| `references/layout-and-space.md` | 4pt基準の9段スペーシングスケール。`gap` を使い、兄弟要素に `margin` を使わない。名前付きz-index 6段。影は1種類のみ、重ねない。 |
| `references/interaction-and-states.md` | **全インタラクティブ要素に8状態**（default / hover / focus-visible / active / disabled / loading / error / success）を必ず実装。 |
| `references/motion.md` | モーション規律。`prefers-reduced-motion` の尊重。 |
| `references/anti-patterns.md` | トークン直書き禁止、偽ブラウザ/IDEクローム禁止、`z-index: 9999` 禁止、カード・イン・カード禁止、等幅な3カラム特徴グリッド禁止。 |
| 規律6 | コントラスト：本文 4.5:1 以上、UI境界 3:1 以上。 |

### 適用しない（アプリUIには不適切）

- マクロ構造（hero → features → CTA → footer）の選択
- ナビ／フッターのアーキタイプ（N1〜N13、Ft1〜Ft8）
- ヒーロー演出（HP1〜HP4）、エンリッチメント
- テーマカタログのローテーション（アプリは**1つの固定テーマ**を持つ。毎回違う見た目になっては困る）
- 非対称・グリッド破りの「意図的なアンバランス」の一部 —— **道具としての予測可能性を優先する**。ただし「全部センター寄せ」「全部同じ余白」は依然として禁止

> **判断に迷ったら：WAKARUは読むための道具である。装飾よりも、情報密度・可読性・操作の予測可能性を優先する。**

## 2. デザイントークン（`src/styles/tokens.css`）

**すべての色・空き・字は必ずここに定義し、コンポーネントからは `var()` で参照する。CSS中に生の色値・px値を書くことを禁止する（Hallmark 規律3）。**

> 以下のコードブロックは初期仕様時の設計記録であり、実装値としてコピーしないこと。現行値は
> `src/styles/tokens.css` と `design.md` を参照する。現在の主要値はコントロール/行/タブ `2.25rem`、
> ツールバー `3.25rem`、角丸 8/12/16px、白/黒を基準にした無彩色面である。

  --space-xl:  2.5rem;    /* 40px */
  --space-2xl: 4rem;      /* 64px */
  --space-3xl: 6rem;      /* 96px */

  /* ツールUIのための密度トークン。--space-* とは別に持つ */

  --gap-tight:     var(--space-2xs);

### 表示サイズ（FR-C5）

`html` の `font-size` を変えるだけで**文字とUIの両方**がスケールするよう、すべての寸法を `rem` で書く。

```css
:root[data-scale="80"]  { font-size: 12.8px; }
:root[data-scale="90"]  { font-size: 14.4px; }
:root[data-scale="100"] { font-size: 16px; }
:root[data-scale="110"] { font-size: 17.6px; }
:root[data-scale="125"] { font-size: 20px; }
:root[data-scale="150"] { font-size: 24px; }
```

**px を直書きしてよいのは、`--radius-*`・ヘアライン `1px`・影のオフセットだけ。** それ以外は `rem`。

### モノトーン（FR-C4、草案の明示要件）

> 「アプリ内のUIから、開いている資料まで、アプリで表示されているもの全てを白黒にする」

```css
:root[data-monochrome="true"] {
  filter: grayscale(1);
}
```

実装上の注意（**必ず守ること**）：
- `filter` を `html` に当てると `position: fixed` の要素が新しい包含ブロックを作られて浮く。**アプリのルートは `#app` 1つの固定レイアウトにし、`fixed` を使わず `position: absolute` + 親の `position: relative` で組む。** サイドバー・モーダル・トーストも `#app` 内の絶対配置で作る。
- `<video>` と `<canvas>` にも `filter` は継承される（＝資料も白黒になる。要件通り）。
- **モノトーン時は色だけに依存した情報表現が全滅する。** 状態（成功/警告/エラー）、ソース種別、引用のハイライトは、**常にアイコンまたは形状を併用する**こと。これはモノトーン機能のためだけでなく、色覚特性への配慮でもある（NFR-8）。
- 印刷・スクリーンショット時も維持する。

サイドバーを開くと（FR-N1）：

┌──────────────────────────────────────────────────────────────┐
│ ≡  WAKARU · <プロジェクト名>            [Illustrator] [設定] │
├─────────────────┬────────────────────────────────────────────┤
│ ▓▓ サイドバー ▓▓ │                                            │
│ ▓ (半透明・      │   現在のページはそのまま。押し出されない。     │
│ ▓  覆いかぶさる) │   背後は暗幕（scrim）で少し沈む。            │

### 3.1 サイドバー（FR-N1, FR-N2）

**草案の明示要件：「半透明で、開いた時は現在開いているページの上にそのままかぶさるように」**
→ **レイアウトを押し出さない。`position: absolute` のオーバーレイとして重ねる。**

```css
.sidebar {
  position: absolute; inset-block: 0; inset-inline-start: 0;
  inline-size: 17rem;
  z-index: var(--z-dropdown);
  background: color-mix(in oklab, var(--color-paper-2) 86%, transparent);
  backdrop-filter: blur(16px) saturate(1.1);
  border-inline-end: 1px solid var(--color-rule);
  transform: translateX(-100%);
  transition: transform var(--dur-normal) var(--ease-out);
}
.sidebar[data-open="true"] { transform: translateX(0); }

.scrim {
  position: absolute; inset: 0; z-index: calc(var(--z-dropdown) - 1);
  background: var(--overlay-scrim);
  opacity: 0; pointer-events: none;
  transition: opacity var(--dur-normal) var(--ease-out);
}
.scrim[data-open="true"] { opacity: 1; pointer-events: auto; }

@media (prefers-reduced-motion: reduce) {
  .sidebar, .scrim { transition-duration: 1ms; }
}
```

- `backdrop-filter` 非対応環境では不透明度を上げる（`@supports not (backdrop-filter: blur(1px))`）
- **フォーカストラップ**：開いている間、Tabはサイドバー内を循環。`Esc` で閉じ、開く前の要素へフォーカスを戻す
- 背後はスクロールロック（FR-N4）

**項目の並び（草案通り、上から）**

| 位置 | 項目 | 挙動 |
|---|---|---|
| 1（最上位） | **ホーム** | プロジェクト作成・一覧 |
| 2 | **ファイルモディファイヤ** | §6 |
| 3〜 | **各プロジェクト** | 名前・最終閲覧・ソース数。ドラッグで並べ替え。右クリックで 開く/名前変更/エクスポート/アーカイブ/削除 |
| 最下部 | **検索** | 全プロジェクト横断検索 |

プロジェクト一覧が多い場合、3の領域だけがスクロールし、1・2・最下部は固定する。

## 4. ホーム

- プロジェクトのカードグリッド（`repeat(auto-fill, minmax(15rem, 1fr))`）
- 各カードに：名前・ソース数・最終閲覧・小さなサムネイル群（先頭4ソース）
- 先頭に「＋ 新規プロジェクト」カード
- **空状態**：0件のときは中央に短い説明と「はじめる」ボタン、その下に「ZIPからインポート」。
  空状態でイラストや装飾を足さない（Hallmarkのアンチパターン：意味のない装飾）

> **Hallmark注意**：等幅カードが並ぶだけになるので、カードの中身に階層を作ること（名前は `--fs-lg`、メタは `--fs-2xs` の `--color-muted`）。全部同じフォントサイズのカードは「生成物っぽさ」の典型。

## 5. プロジェクト画面

```
┌──────────────────────────────────────────────────────────────┐
│ ≡  WAKARU · 量子計算の講義                        [⚙ 設定]   │
├──────────────────────────────────────────────────────────────┤
│ [ 資料を見る ]  [ Studio ]                                    │ ← ペインタブ（草案「上部に2つのタブ」）
├──────────────────────────────────────────────────────────────┤
│ (各ペインの内容)                                              │
└──────────────────────────────────────────────────────────────┘
```

- 上部の2タブは**セグメンテッドコントロール**（トグル的な見た目）にして、下のタブ群（ファイルタブ）と視覚的に混同させない。
  - ペインタブ：太字・下線なし・背景で選択を示す
  - ファイルタブ：細字・下線で選択を示す
- ペインを切り替えても、各ペインのタブ状態は保持される

### 5.1 Viewerペイン（草案「1 資料を見るタブ」）

```
┌──────────────────────────────────────────────────────────────┐
│ [🏠] [ 量子計算入門.pdf ×] [ 講演.mp4 ×] [ notes.md ×] [+]    │ ← タブ群
├──────────────────┬───────────────────────────────┬───────────┤
│                  │                               │  ◀ ハンドル│
│  (ホームタブ選択時)│   プレビュー（編集不可）        │           │
│  ソース一覧       │                               │  Live      │
│  File explorer風  │                               │  Illustrator
│                  │                               │  ドロワー   │
└──────────────────┴───────────────────────────────┴───────────┘
```

**タブ規約**
- 最左は **ホームタブ（ソース一覧）**。ホームアイコンのみ、ラベルなし。**閉じるボタンを出さない**（FR-V1）
- 新しいファイルは**ホームタブの右側**に追加する（C-4：草案の「左側」は誤記）
- 同じソース・同じロケータのタブは再利用する（重複タブを作らない）
- タブ幅：最小 `6rem`、最大 `14rem`。テキストは `text-overflow: ellipsis`。**タブ内のテキストを2行にしない**（Hallmark 規律5）
- タブが溢れたら横スクロール（スクロールバーは細く、`overflow-x: auto`）
- ドラッグで並べ替え可、ダブルクリックでピン留め
- 中クリックで閉じる
- タブのアイコンでソース種別を示す（モノトーン対応のため色に依存しない）

**ソース一覧タブ（ホームタブ）の中身**
- 上部：検索入力・並べ替え（追加順/名前/種別/サイズ）・表示切替（リスト/グリッド）
- 本体：仮想スクロールのリスト。1行 `--row-height`。列は「アイコン｜名前｜種別｜ページ/長さ｜状態」
- 状態バッジ：`queued`（点線円）/ `analyzing`（進捗リング＋%）/ `ready`（何も出さない）/ `ready_partial`（△）/ `failed`（！）
  **`ready` のときはバッジを出さない。** 全行にバッジが並ぶとノイズになる
- ドロップゾーン：リスト全体。ドラッグ中は破線ボーダーで示す
- 空状態：「資料をドロップするか、＋から追加」＋対応形式の一覧
- 右クリック：開く / 再解析 / Finderで表示 / 名前変更 / 削除

**プレビュー（FR-V4：編集不可）**

| 種別 | 描画 |
|---|---|
| PDF/スライド | Rust側でラスタライズした WebP を表示。連続スクロール or 単ページ切替（設定）。ズーム 50〜400%、幅に合わせる／全体表示 |
| 画像 | ズーム・パン。`analysis.json` の領域をトグルでオーバーレイ表示 |
| 音声 | 波形（`derived` に事前生成したピークデータ）＋トランスクリプトの時刻同期スクロール。行クリックでシーク |
| 動画 | `<video>`（`asset:` 参照）＋右にトランスクリプト＋下にキーフレーム帯 |
| 表計算 | 仮想化グリッド。シートタブ。読み取り専用（セル選択とコピーは可） |
| md / txt / コード / JSON | `shiki` の読み取り専用ビュー。行番号あり。折り返しトグル |
| Webリンク | 保存済みリーダービュー（Markdown描画）＋「元のURLを開く」（**外部ブラウザで開く。アプリ内でレンダリングしない**） |

**編集不可であることをUIで示す**：ツールバーに小さく「閲覧専用」と表示し、テキスト選択は可能にする（コピーはできる）。

### 5.2 Live Illustrator ドロワー

- **設定でオンのときだけ**、Viewerの右端に幅 `0.5rem` のハンドルが出る（FR-V5）。オフならハンドルも出さない
- ドラッグまたは `Cmd/Ctrl+\` で開く。幅は `20rem`〜`44rem` の間でリサイズ可。幅は永続化
- 通常幅では**Viewerを押し出す**（サイドバーと違い、こちらは並置）。幅42rem以下では本文幅をゼロにしないため、Viewer上へ重ねて表示する
- 構成（上から）：

```
┌──────────────────────────────┐
│ 解説   [かんたん|標準|くわしい] │ ← 詳細度セグメント
│ ページ 12 / 48        [↻ 再生成]│

### 5.3 Studioペイン（草案「2 Studioタブ」）

```
┌──────────────────────────────────────────────────────────────┐
│ [ 要約作成 ] [ スライド案 ] [ 解説: p.12 ] [+]                │ ← 自由に増やせるタブ群
├────────────────────────────────────────┬─────────────────────┤

- 入力欄で `@` を押すとタブ参照の補完（FR-T4）
- 参照範囲セレクタ：ページ / ソース / プロジェクト全体
- **ツール承認カード**：チャット内にインラインで出す。モーダルにしない（会話の流れを切らない）

  - ボタン：「許可」「拒否」「このツールは常に許可」
- **引用**：本文中に `[1]` の上付き。ホバーで出典プレビュー、クリックでViewerペインへ切り替えて該当ページを開く
- アーティファクトカード：ファイル名・サイズ・種別アイコン・プレビュー・[ソースに追加][ダウンロード]

### 5.4 レスポンシブ表示と低いウィンドウ

- アプリルートは `100dvh` を使用し、OSの動的表示領域と一致させる。文書全体には横スクロールを作らない
- 設定は42rem以下で左レールを上部の横スクロール式タブへ切り替え、本文に残りの高さを割り当てる
- Studioは60rem以下で作業領域、42rem以下で会話レールを畳み、会話と入力欄を必ず残す
- ホームカード、検索欄、AI役割設定、ファイル変換の2列編集領域は、狭幅で1列へ落とす
- 高さ30rem以下では余白を縮め、画面単位ではなく本文・会話・設定パネルなど作業領域自身を縦スクロールさせる
- ダイアログ、トースト、サイドバー、ドロワーの最大幅は常に現在のviewport以下とする
- 基準確認寸法は `240×320`, `320×568`, `568×320`, `960×640`, `1280×840`, `1600×500`。表示倍率80%と150%も確認する

### 8.1 プロジェクト管理（草案の明示要件）

> 「チェックボックス付きのリストみたいなUIでプロジェクトを管理」

```
┌──────────────────────────────────────────────────────────────┐
│ [ ] すべて選択                        [インポート（ZIP）…]     │
├──────────────────────────────────────────────────────────────┤
│ [✓] 量子計算の講義      12ソース  340MB  最終 2026-07-30      │
│ [ ] 論文まとめ           5ソース   82MB  最終 2026-07-12      │
│ [✓] 会議録画            31ソース  2.1GB  最終 2026-06-28  📦  │ ← 📦=アーカイブ済み
├──────────────────────────────────────────────────────────────┤
│ 2件選択中   [ZIPでダウンロード] [アーカイブ] [削除]            │

```

- **ZIPでダウンロード**：選択した各プロジェクトを**プロジェクトごとに個別のZIP**にする（草案：「プロジェクトのデータ毎にZIPしたもの」）。出力先はフォルダ選択ダイアログ

- **アーカイブ**：トグル。アーカイブ済みはサイドバーから消え、この一覧では 📦 付きで残る
- **削除**：確認ダイアログでプロジェクト名の再入力を要求。複数選択時は件数の入力
- 進捗はモーダルではなくインラインの進捗行で出し、他の操作を止めない

## 9. コンポーネント規約

### 9.1 8状態（Hallmark 必須）

**すべてのインタラクティブ要素（Button, IconButton, Tab, ListRow, Input, Select, Checkbox, Switch, Slider）に8状態を実装する。**

| 状態 | 実装 |
|---|---|
| default | — |
| hover | `--color-paper-2` へ背景変化 or 罫線強調。**150ms以内**で反応 |
| focus-visible | `outline: 2px solid var(--color-focus); outline-offset: 2px`。**`outline: none` を書くことを禁止** |
| active | わずかな沈み込み（`transform: translateY(0.5px)` または背景をさらに1段） |
| disabled | `opacity: 0.45; cursor: not-allowed; pointer-events: none`。**なぜ無効かをtooltipで説明する** |
| loading | ボタン内スピナー＋幅を維持（レイアウトシフト禁止）。ラベルは維持したまま |
| error | 罫線を `--color-danger` に＋⚠アイコン＋メッセージ。**色だけで示さない** |
| success | ✓アイコン＋短い確認。2秒で default に戻る |

開発中は `src/components/__preview__/` に8状態デモページを置き、目視確認できるようにする（Hallmark の 8-state demo wrapper に相当）。**製品ビルドには含めない。**

### 9.2 空状態・読み込み状態・エラー状態

**すべてのリスト・パネルに3状態を必ず用意する。** 「データが無いときに何も出ない」を許さない。

| 状態 | 内容 |
|---|---|
| 空 | 何が入る場所かの1文＋最初の操作へのCTA。装飾イラストは置かない |
| 読み込み中 | スケルトン（実際のレイアウトと同じ形）。スピナー単独は使わない |
| エラー | 何が起きたか（技術語を避ける）＋再試行ボタン＋詳細の折りたたみ |

### 9.3 禁止事項（Hallmark anti-patterns より、本アプリ向けに抜粋）

- ❌ 生の色値・フォント名をコンポーネントCSSに書く（必ずトークン経由）
- ❌ 斜体の見出し
- ❌ `z-index` の直値
- ❌ 影の重ねがけ、ダーク背景での影（グローになる）
- ❌ カード・イン・カード（枠の中に枠）
- ❌ 等幅3カラム＋アイコン＋2行見出し＋3行本文の「特徴グリッド」
- ❌ 全要素の余白が同一（リズムが死ぬ）
- ❌ すべてセンター寄せ
- ❌ 偽のブラウザバー／偽のIDEクローム／偽のターミナル枠
- ❌ 存在しない数値・実績の捏造（空状態に「1,234件のドキュメント」等のダミーを置かない）
- ❌ `outline: none`
- ❌ アクセント色をボタン全面の塗りに多用する（画面の3%以下）

### 9.4 モーション

- 既定は `--dur-fast`（140ms）。**300msを超えるアニメーションを作らない**（道具は速く感じるべき）
- ドロワー・サイドバーは `--dur-normal`（220ms）
- **`prefers-reduced-motion: reduce` のとき、全 transition を 1ms にする**（無効化ではなく即時完了。状態遷移自体は保つ）
- ストリーミングテキストにタイプライター演出を足さない（トークン到着そのものが動きである）
- レイアウトシフトを起こすアニメーションを禁止（`width`/`height` ではなく `transform`/`opacity` を使う）

## 10. アクセシビリティ（NFR-8）

- すべての操作がキーボードで到達可能。**タブ順序は視覚順序と一致させる**
- タブ群は WAI-ARIA の `tablist` / `tab` / `tabpanel` パターン。矢印キーで移動、`Home`/`End` で端へ
- ドロワー・モーダルは `role="dialog" aria-modal="true"` ＋フォーカストラップ＋`Esc` で閉じる
- ストリーミング中の領域は `aria-live="polite"`（`assertive` にしない）
- アイコンのみのボタンは必ず `aria-label`
- 進捗は `role="progressbar"` ＋ `aria-valuenow`
- コントラスト：本文 4.5:1、UI境界 3:1（トークンは既にこれを満たすよう設計してある。**変更したら再検証すること**）
- **色だけで情報を伝えない**（モノトーンモードがあるため特に重要。§2）
- 最小クリック領域 `2.75rem × 2.75rem`（小さいアイコンは疑似要素でヒット領域を拡張）
