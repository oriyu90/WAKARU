# 07 · 設定・多言語・配布

## 1. 設定スキーマ

`app.db` の `settings` テーブルにJSONで保存。型は `src-tauri/src/domain/settings.rs` に定義し `ts-rs` でTSへ出す。

```ts
type Settings = {
  general: {
    startupView: "home" | "last_project";
    dataDir: string;                 // 表示用。変更は app_move_data_dir 経由
    checkUpdatesOnStart: boolean;    // 既定 true。更新の適用は常に手動
  };

  ai: {
    roles: {
      chat:      RoleBinding | null;
      vision:    RoleBinding | null;
      embedding: RoleBinding | null;   // null なら local を使う
      organizer: RoleBinding | null;   // null なら chat と同じ
    };
    localEmbedding: {
      model: "multilingual-e5-small" | "bge-m3" | "bge-small-en-v1.5";
      downloaded: boolean;
    };
    contextTokens: number;      // 既定 32768
    maxOutputTokens: number;    // 既定 4096
    maxImagesPerRequest: number;// 既定 4
    rerank: boolean;            // 既定 false
    concurrency: number;        // 既定 3
    warnAboveTokens: number | null; // 既定 null（警告しない）
  };

  transcription: {
    whisperModel: "base" | "small" | "medium" | "large-v2";
    language: "auto" | string;
    hardwareAccel: boolean;     // 既定 true
  };

  display: {
    theme: "light" | "dark" | "system";   // FR-C3
    monochrome: boolean;                   // FR-C4
    scale: 80 | 90 | 100 | 110 | 125 | 150;// FR-C5
    readingFont: "serif" | "sans";
  };

  language: {
    ui: "en" | "ja" | "zh-Hans";           // FR-C2
    aiResponse: "follow_ui" | "en" | "ja" | "zh-Hans" | "match_source";
  };

  illustrator: {
    enabled: boolean;                       // FR-L1
    defaultLevel: "simple" | "standard" | "detailed";
    defaultScope: "page" | "source" | "project";
    prefetchNext: boolean;                  // 既定 true
    carryOverPreviousPage: boolean;         // 既定 true
  };

  ingest: {
    concurrency: number;         // 既定 max(1, cores/2)
    fetchWebImages: boolean;     // 既定 false
    allowPrivateNetwork: boolean;// 既定 false（SSRF防止）
  };

  sandbox: {
    commandTimeoutSec: number;   // 既定 60、最大 600
    autoAllowNewFileWrites: boolean; // 既定 false
  };
};

type RoleBinding = { profileId: string; model: string; params: Record<string, unknown> };
```

### 既定値の原則

- **初回起動時、AIは未設定**。設定していない状態でもアプリは起動し、ソースの取り込み（テキスト抽出まで）・閲覧・検索（FTSのみ）ができる。
- AIが必要な操作を試みたとき、モーダルで止めるのではなく**その場にインラインで「AIを設定する」CTA**を出す。
- 初回起動時に**セットアップウィザードを1回だけ**出す：言語 → テーマ → AI接続（スキップ可）→ 完了。スキップしても後から設定できることを明示する。

## 2. 多言語（i18n）

### 2.1 対応言語

草案の指定通り **English / 日本語 / 中文（簡体）** の3つ。

| コード | 表示名 | 備考 |
|---|---|---|
| `en` | English | フォールバック言語 |
| `ja` | 日本語 | |
| `zh-Hans` | 简体中文 | 繁体は v1.0 対象外 |

### 2.2 実装規約

- `i18next` + `react-i18next`。名前空間は画面単位（`common`, `home`, `viewer`, `studio`, `settings`, `errors`, `fileModifier`）
- **キーは英語の意味を表す階層キー**（`viewer.tab.close`）。英文そのものをキーにしない
- **UIに英語のハードコード文字列を残さない。** CI で `grep` による検出（ASCII文字列リテラルがJSXテキストに現れたら警告）を入れる
- 複数形は i18next の複数形サポートを使う（`_one` / `_other`）。**中国語・日本語は複数形が無いので `_other` だけを定義する**
- 日付・時刻・数値は `Intl.DateTimeFormat` / `Intl.NumberFormat` に言語を渡す
- ファイルサイズは `Intl.NumberFormat` + 単位のローカライズ
- **Rust側のエラーは `i18n_key` を返し、翻訳はフロントで行う**（[`02_アーキテクチャ.md`](02_アーキテクチャ.md) §4）

### 2.3 UI言語とAI応答言語の分離（FR-C2）

- `language.ui` … アプリのUI
- `language.aiResponse` … AIの回答・Live Illustratorの解説
  - `follow_ui`（既定）… UI言語と同じ
  - `match_source` … ソースの検出言語に合わせる
  - 明示指定 … `en` / `ja` / `zh-Hans`

システムプロンプトに応答言語を注入する。**中国語ソースを日本語で読みたい人**、**英語論文を日本語で解説してほしい人**がこの機能の主な対象。

### 2.4 フォントとCJK

- `--font-ui` / `--font-read` に日中それぞれのフォントをフォールバックチェーンで並べる（[`06_UI仕様.md`](06_UI仕様.md) §2）
- **CJKフォントを同梱しない**（数十MB×3言語でNFR-7を破る）。OS標準フォント（macOS: Hiragino/PingFang、Windows: Yu Gothic/Microsoft YaHei、Linux: Noto）にフォールバックする
- 同梱するのは可変ラテンフォント（Inter, Source Serif 4, JetBrains Mono）のみ。**サブセット化してWOFF2で同梱**する
- `lang` 属性を `<html>` に設定する（CJK統合漢字の字形が言語で変わるため。**必須**）

### 2.5 翻訳の品質

- **機械翻訳のまま出さない。** 特に「解説」「取り込み」「作業領域」といった本アプリ固有の概念語は、3言語それぞれで自然な語を選ぶ
- 用語集を `docs/GLOSSARY.md` に作り、3言語の対訳を固定する（実装AIは新しい用語を追加したらここに追記する）

| 概念 | en | ja | zh-Hans |
|---|---|---|---|
| Project | Project | プロジェクト | 项目 |
| Source | Source | ソース | 资料 |
| Live Illustrator | Live Illustrator | ライブ解説 | 实时讲解 |
| Studio | Studio | Studio | 工作台 |
| File Modifier | File Modifier | ファイル変換 | 文件转换 |
| Workspace | Workspace | 作業領域 | 工作区 |
| Citation | Citation | 引用 | 引用 |
| Chunk | — (内部語。UIに出さない) | — | — |
| Archive | Archive | アーカイブ | 归档 |
| Monochrome | Monochrome | モノトーン | 单色 |

## 3. モノトーン実装の詳細（FR-C4）

[`06_UI仕様.md`](06_UI仕様.md) §2 に CSS を記載済み。ここでは**壊れやすい箇所**を列挙する。実装時に必ず確認すること。

| 箇所 | 注意点 |
|---|---|
| `position: fixed` 要素 | `filter` を持つ祖先があると包含ブロックが変わる。**アプリ全体で `fixed` を使わない設計**にする |
| `<video>` | `filter` は継承される。動画も白黒になる（要件通り） |
| `<canvas>`（波形描画） | 同上。ただし描画時の色分けが潰れるので、**波形は形状で区別**する |
| `<img>` のサムネイル | 継承される |
| ネイティブのスクロールバー | `filter` の影響を受けない場合がある。カスタムスクロールバー（`::-webkit-scrollbar`）で統一する |
| OSのファイルダイアログ | 影響外。これは仕様として許容 |
| コードのシンタックスハイライト | 色が全て潰れる。**モノトーン時は shiki のテーマを `github-light`/`github-dark` から、太字と斜体で区別するモノクロテーマへ切り替える** |
| 引用ハイライト | 色ではなく**下線＋左罫線**で示す（元から色に依存しない設計にする） |
| 状態バッジ | 色ではなく**アイコン形状**で区別（○ △ ！ ✓） |

## 4. 表示サイズ（FR-C5）

- `html { font-size }` を切り替えるだけで全体がスケールする（[`06_UI仕様.md`](06_UI仕様.md) §2）
- **150% でもレイアウトが壊れないこと**を全画面で検証する（[`09_受け入れ基準とテスト.md`](09_受け入れ基準とテスト.md)）
- 資料プレビューのズームは**別の概念**。表示サイズはUIとテキストに、ズームは資料の描画倍率に効く。両方を独立して使えるようにする
- ウィンドウ最小サイズ：`960 × 640`（125%時にも主要画面が成立する幅）。150%時は横スクロールを許容せず、右パネルを自動的に折りたたむ

### 5.2 依存ライセンス（I-8）

**GPL / AGPL の依存を入れない。** ビルド時に自動検査する：

```bash
cargo install cargo-deny
cargo deny check licenses
npx license-checker --production --failOn "GPL-2.0;GPL-3.0;AGPL-3.0;SSPL-1.0"
```

`deny.toml` の `allow` リスト：`MIT`, `Apache-2.0`, `BSD-2-Clause`, `BSD-3-Clause`, `ISC`, `Unicode-DFS-2016`, `Zlib`, `MPL-2.0`（ファイル単位コピーレフトなので可）。

```jsonc
{

  "identifier": "com.yukiorita.wakaru",
  "version": "1.0.0",
  "bundle": {
    "active": true,
    "targets": ["dmg", "app", "nsis", "deb", "appimage"],
    "icon": ["icons/32x32.png", "icons/128x128.png", "icons/icon.icns", "icons/icon.ico"],
    "copyright": "Copyright © 2026 Yuki Orita",
    "licenseFile": "../LICENSE",
    "shortDescription": "AI notebook for your own documents",
    "longDescription": "WAKARU explains the page you are reading, and lets you ask your own sources anything. Works with any OpenAI-compatible endpoint, including local models."
  },
  "app": {
    "windows": [{
      "title": "WAKARU",
      "width": 1280, "height": 840,
      "minWidth": 960, "minHeight": 640,
      "resizable": true,
      "dragDropEnabled": true
    }],
    "security": {
      "csp": "default-src 'self'; img-src 'self' asset: http://asset.localhost data: blob:; media-src 'self' asset: http://asset.localhost blob:; style-src 'self' 'unsafe-inline'; font-src 'self' data:; connect-src 'self' ipc: http://ipc.localhost"
    }
  }
}
```

**CSP の要点**
- `script-src` を `'self'` に限定（`'unsafe-eval'` を入れない）
- 外部への `connect-src` を許さない。**AIエンドポイントへの通信は全てRust側から行う**（フロントから直接fetchしない）。これによりAPIキーがWebViewに一切載らない（I-4）
- `img-src`/`media-src` に `asset:` を許可（プレビュー用）

### 5.6 署名・公証

| OS | 対応 |
|---|---|
| macOS | Developer ID で署名 + notarize。証明書が無い場合は「未署名ビルド」として配布し、Gatekeeper回避手順をREADMEに明記 |
| Windows | Authenticode 署名（証明書がある場合）。無い場合は SmartScreen 警告が出る旨をREADMEに明記 |
| Linux | 署名なし（AppImage + deb） |

**署名の有無でアプリの機能を変えない。** 未署名でも全機能が動くこと。

### 5.7 自動更新

- `tauri-plugin-updater`。**更新チェックは起動時に1回、適用は常にユーザーの明示操作**。サイレント更新はしない
- 更新サーバが無い場合は機能を無効化してよい（設定でオフ）
- 更新前に **`app.db` と全 `project.db` のバックアップ**を取る

## 6. ログとプライバシー（NFR-10）

- ログは `<appdata>/logs/wakaru.log.YYYY-MM-DD`。7日分でローテーション
- **ログにAPIキー・プロンプト本文・資料本文を書かない。** 書いてよいのは：操作名、所要時間、エラーコード、ソースID、モデル名、トークン数
- 「ログフォルダを開く」ボタンを設定に置く（不具合報告用）
- **テレメトリ・クラッシュレポートの自動送信を実装しない。** 実装したくなったら必ずオプトインにし、送信内容を全て表示すること
- 外部通信を行うのは以下だけ。これ以外を追加しない：
  1. ユーザーが設定したAIエンドポイント
  2. ユーザーが明示的に追加したWebリンクの取得
  3. whisper / 埋め込みモデルのダウンロード（ユーザー操作時のみ）
  4. 更新チェック（設定でオフ可）
- 設定 → このアプリについて に「WAKARUが通信する先」の一覧を常時表示する
