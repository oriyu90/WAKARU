# 09 · 受け入れ基準とテスト

## 0. テスト戦略

| 層 | 対象 | ツール | 方針 |
|---|---|---|---|
| Rust 単体 | チャンク化、locator正規化、パス検査、CJK bi-gram、マイグレーション、RRF | `cargo test` | **純粋関数を厚く**。ここが一番安く守れる |
| Rust 統合 | 取り込みパイプライン（形式別）、検索、エクスポート/インポート往復 | `cargo test --test integration` | `tests/fixtures/` の実ファイルを使う |
| AIモック | AI Gateway、ストリーミング、リトライ、縮退 | `wiremock` | **本物のAPIをテストで叩かない** |
| TS 単体 | ストア、フォーマッタ、i18n補間 | Vitest | |
| コンポーネント | 8状態、キーボード操作、ARIA | RTL + `vitest-axe` | |
| E2E | 主要フロー（UF-1/2/3） | Playwright（Tauri WebDriver） | 数を絞る。壊れやすいので主要フローのみ |
| 手動 | 見た目、モノトーン、表示サイズ、A11y、OS差 | チェックリスト（§6, §7） | 各フェーズ末に実施 |

### テスト用フィクスチャの規約

`tests/fixtures/` に置くファイルは **著作権上問題のないものだけ**（自作 / パブリックドメイン / CC0）。
最低限そろえるもの：

```
fixtures/
├─ pdf/text-only.pdf          （テキストPDF、3ページ、日本語+英語）
├─ pdf/scanned.pdf            （画像のみ、OCR経路の検証）
├─ pdf/with-table.pdf         （罫線付きの表）
├─ pdf/encrypted.pdf          （パスワード付き）
├─ slides/deck.pptx           （ノート付き、5枚）
├─ docx/report.docx           （見出し階層・表・脚注）
├─ image/photo.jpg            （EXIF回転あり）
├─ image/chart.png            （棒グラフ）
├─ image/tall-screenshot.png  （アスペクト比 6:1、タイル分割の検証）
├─ audio/speech-ja-30s.wav
├─ audio/silence.wav          （無音警告の検証）
├─ video/slides-talk-60s.mp4  （音声+スライド切替、キーフレーム検証）
├─ sheet/data.xlsx            （複数シート、数式、1000行）
├─ text/{notes.md, log.txt, data.json, records.jsonl, main.rs}
└─ broken/{truncated.pdf, not-really.png, zero.bin}
```

## 4. AIモックの方針

ローカルのモックHTTPサーバで OpenAI互換とAnthropic互換の双方を検証し、以下のシナリオを用意する：

| シナリオ | 検証 |
|---|---|
| 正常ストリーミング | delta が順に届き `[DONE]` で終わる |
| `[DONE]` なしで切断 | エラーにせず `truncated: true` で終わる |
| 429 → 200 | リトライして成功する |
| 429 × 4 | 3回リトライ後にエラー |
| 401 | リトライしない |
| Vision リクエストに 422 | 能力プローブが `vision: false` を返す |
| tool_call を含むストリーム | 承認フローに入る |
| 遅延レスポンス | キャンセルが効く |

**本物のAPIをCIで叩かない。** 実機確認は手動チェックリストで行う。

## 5. プロンプトのゴールデンテスト

システムプロンプトを変更したとき、出力の質が落ちていないかを確認する軽量な仕組み：

1. `tests/golden/illustrator/` に「入力（ページテキスト＋メタ）」と「期待される性質」を置く
2. 実モデル（開発者のローカルLLM）で生成し、以下を**人間が**確認する：
   - ページに書かれていないことを書いていないか
   - 「このページの結論」が最初に来ているか
   - 詳細度の指定が反映されているか（文字数の目安）
   - 応答言語が正しいか
   - 引用タグ `[S1]` が使われているか
3. 結果を `tests/golden/illustrator/results-<date>.md` に残す

**これは自動テストにしない。** LLMの出力を機械的にassertすると壊れやすく、意味のない緑になる。人間の目視を仕組みとして残すのが目的。
